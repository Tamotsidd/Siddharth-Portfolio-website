# Siddhartha Tamrakar — Photography Portfolio

This is a responsive, dark, cinematic photography portfolio.

## Structure
- `index.html` — all page sections and content
- `portraits.html`, `weddings.html`, `events.html`, `street.html`, `nature.html`, `culture.html` — dedicated photography category pages
- `style.css` — responsive design, typography and animations
- `script.js` — mobile menu, scroll reveals, category filters and interactions
- `gallery-data.js` — connects category and design galleries to their local assets
- `assets/images/photography/` — optimized WebP photographs, organized by category
- `assets/images/visual-works/` — replace visual-work thumbnails
- `assets/images/design/` — replace thumbnail/graphic placeholders
- `assets/images/about/portrait.svg` — replace with your portrait
- `assets/video/` — optional local video files

## How to use
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Add new gallery images to their category folders and update `gallery-data.js`.
   Gallery photographs use optimized WebP files.
4. Replace `hello@example.com` and the social `#` links with your real details.
5. For visual works, replace the placeholder cards/buttons with your YouTube/Vimeo links or local `<video>` elements.
6. Open `index.html` in a browser, or use VS Code Live Server.

No framework or build step is required.
